#### 2️⃣ El Link (사회적 기업 협업 자동화)

**문제**: 협업 자료 산발적 탐색 + 반복 행정 비효율로 협업 검토에 **40분 소요**

**솔루션**: 데이터 기반 재분석 → AI 솔루션으로 전면 전환

**프로세스**:

1. 실무자 설문조사 진행 → 진짜 병목 발견
2. 기존 "홍보 웹사이트" 계획 전면 폐기
3. "행정 프로세스 자동화"로 방향 전환

**기술 스택**: React + Spring + Gemini API + Google Apps Script

**구현 기능**:

- 협업 자료 자동 분류·요약 (Gemini API)
- 기업명 입력 → 협업 주제 자동 제안
- 필수 서류·모의 견적 즉시 산출

**결과**: 40분 → 10분 **75% 단축** 🎯 | **최우수상** (2개 수상)
